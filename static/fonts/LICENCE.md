# Fonts shipped with generated pages

Each of these is embedded into the pages the Launch Site Builder produces, so
the page carries its own typography and still opens with no network.

All are used under their own licences and are redistributable:

| Font | Licence |
|---|---|
| Archivo Black | SIL Open Font Licence 1.1 |
| Space Grotesk | SIL Open Font Licence 1.1 |
| Fraunces | SIL Open Font Licence 1.1 |
| JetBrains Mono | SIL Open Font Licence 1.1 |
| Cormorant Garamond | SIL Open Font Licence 1.1 |
| Inter | SIL Open Font Licence 1.1 |
| Bricolage Grotesque | SIL Open Font Licence 1.1 |

The OFL permits embedding in documents and bundling with other software. It
does not permit selling the fonts on their own, which is not what happens here:
they travel inside a page as part of its design.

These are the latin subsets, which is all an English language landing page
needs, and is why each is twenty kilobytes rather than two hundred.
