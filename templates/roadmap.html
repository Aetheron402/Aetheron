Aetheron Roadmap

What is built, what is being built now, and what comes after. Struck through means shipped and running today. Everything else is ordered by what it depends on rather than pinned to a quarter, because dated promises age badly and this page is meant to stay true.

Intelligence Suite (shipped)

  • Contract Intelligence Analyzer: any Ethereum or Solana address returns holder distribution, control surface, liquidity lock state and a scored risk read.
  • Prebuilt Agent Store: nine agents, unlocked with a one time X402 payment.
  • Aetheron SDK: documented in the repository README, with the 402 handshake handled for you rather than reimplemented per client.
  • Infrastructure: one repository, queued workers, reports stored in Postgres so a deploy never loses something a customer paid for.
  • Identity and docs: the interface, the documentation and the type system the whole product is set in.

The Relaunch (now)

  • Every component rebuilt: findings cite the line, field or transaction they came from, so any claim can be checked instead of trusted.
  • Scores are computed, not written: the same input returns the same answer every time, and a data source that does not respond is reported as missing rather than filled in.
  • Every agent on live data: real balances, real market conditions, real holder distribution. Nothing is simulated to look busy.
  • Configured downloads: agents arrive with your settings already written in and a script that installs and starts them in one command.
  • Watch it run: eight of the nine agents can be run live in the store before you pay for one.
  • Live status page: every dependency probed on load, with real latencies and counts taken from the ledger.
  • Open source: the whole platform in one public repository, payment verification included.
  • Token launch: $AETH on Pump.fun. AETH payments activate across every component the moment the mint exists, with no redeploy.

Focus: make every number in the product checkable, then relaunch on that footing.

Next: Agents That Buy For Themselves

  • MCP Server: expose every component over the Model Context Protocol, so an assistant can call Aetheron directly and settle the payment itself.
  • Hosted agent runs: run the monitoring agents on our infrastructure, priced per run through X402. Only the agents that need no keys of yours.
  • Aetheron CLI: bulk prompt and code analysis from a terminal.
  • EVM payments: MetaMask connects today but settlement is Solana only. Paying from an EVM wallet is the missing half.

Later: Composition and Proof

  • X402-Linker: chain components together so one output feeds the next, without a central API in the middle.
  • Orchestration UI: build those chains visually, optimise then analyse then test in a single run.
  • Trust Ledger: certify every generated report by transaction hash, and a tool to verify one you were sent.
  • Transparency dashboard: live transaction flow and component usage, readable by anyone.

Eventually: An Open Marketplace

  • Community components: publish your own and be paid per call, with the split handled on chain.
  • Public registry: every component endpoint, its version and its price, searchable.
  • Multi-chain: Base and Arbitrum alongside Solana.
  • Decentralised storage: report archives on IPFS or Arweave with content proofs.
  • Listings and governance: ecosystem listings once usage is steady, and proposal voting on what gets built.

No dates on this section. It happens when the work before it is done and holding up.
